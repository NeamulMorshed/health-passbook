Severity Architecture

Three-tier interrupt model — calibrated to clinical risk and user autonomy.

01
Critical — Bottom Sheet Block
Used for overdose-risk scenarios. Full screen scrim, animated danger stripe, pulsing icon halo. No auto-dismiss. Primary CTA is always the safe exit (green). Override CTA is ghost-styled to reduce affordance. Requires explicit user decision before proceeding.
02
Warning — Center Modal Interrupt
Used for temporal / scheduling anomalies. Scale-up entrance forces attention before the user can interact with the app. Amber color signals reversibility. Side-by-side timezone card makes the change visceral. Both CTAs are valid — no "wrong" choice, just different trade-offs.
03
Soft — Non-blocking Toast
Used for improbable but possible inputs. Slides up without covering the form. Smart unit-confusion suggestion pre-empts the most common error. 6-second countdown is visible (progress bar). Confirm path flags the entry as user-verified outlier for the clinician portal, preserving data integrity without blocking the user.
